# Stitch entry assets

These nine PNG files are byte-for-byte local copies of the `img src` assets in the four supplied Stitch HTML files under `design-references/gorut-stitch-entry/source/stitch_gorut_mobile_ui_design_system/`.

Names follow `<source screen>-<zero-based image order>.png`. No generated replacement artwork is used. The port retains the inline SVGs; the reset screen's remote Material Symbols font is replaced with project Lucide SVG equivalents. Plus Jakarta Sans is served locally by the project's Next.js font pipeline.
